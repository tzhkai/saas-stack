## Which option should you choose?

### Starter

Choose Starter when you are learning the workflow or maintaining a small personal project.

### Pro

Choose Pro when you need reusable templates and a more repeatable documentation process.

### Team

Choose Team when multiple people need a shared workspace and consistent documentation standards.
